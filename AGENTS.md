# CloudReady AZ-900 — Agent Instructions

## Project goal
Build an unofficial AZ-900 study app using React, TypeScript, Vite, and CSS.

## Required features
- Topic selection for cloud concepts, Azure architecture and services, and Azure management and governance.
- Original multiple-choice practice questions.
- Immediate answer feedback and accurate explanations.
- Quiz progress, scoring, results, topic performance, and weak-area recommendations.
- Persist learning progress in localStorage.
- Responsive, accessible interface.

## Rules
- Inspect relevant files before editing.
- Make small, focused changes.
- Preserve working functionality and existing project configuration.
- Do not add backend services, login, paid APIs, or dependencies without approval.
- Do not invent Azure facts, test results, or deployment status.
- Use original practice questions; never reproduce real exam questions.
- Explain uncertainty and flag facts that require verification against official Microsoft documentation.
- Run npm run build and npm run lint after meaningful changes.
- Report exactly what was changed, what was tested, and any remaining failures.
